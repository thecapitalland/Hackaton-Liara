# محدودیت‌ها و وضعیت صادقانه

## محدودیت‌های API
- رول‌بک مستقیم، استریم لاگ، plans مستقل، health-check و ثبت/خرید دامنه در API جدول مرجع نیستند. راهنماها جایگزین را اعلام می‌کنند، نه endpoint ساختگی.
- دیپلوی GitHub با GitHub Action و Liara CLI انجام می‌شود؛ راهنما فایل workflow می‌دهد، آن را خودکار ایجاد یا منتشر نمی‌کند.
- لیارا `.liara.run` رایگان می‌دهد؛ دسترسی زنده به `agate-liara.liara.run` هنوز بررسی نشده است.

## باقی‌مانده‌های پیاده‌سازی / آزمون
- احراز هویت، پاسخ‌های live، انتخاب bundlePlanID، شکل متریک و واحدهای CPU/RAM باید با preflight حساب واقعی تأیید شوند. جدول اولیه به‌معنای live-verified نیست.
- preflight در صورت خطای هر endpoint gate را باز نمی‌کند؛ ممکن است endpoint اختیاری در بعضی حساب‌ها در دسترس نباشد. ابتدا علت مستند و مسیر مربوط اصلاح شود؛ gate را دستی دور نزنید.
- `connect_domain` افزودن دامنه، خواندن DNS و پیشنهاد SSL دارد؛ نوشتن zone/record در Liara DNS پیاده نشده است. رکوردها را دستی ثبت کنید.
- روند فعلی در نبود elicitation به چند فراخوانی نیاز دارد: انتخاب پلن، ساخت اپ، تأیید CLI، اجرای action، فراخوانی دوبارهٔ deploy_project.
- پیشرفت دیپلوی در خروجی نهایی جمع می‌شود؛ notification لحظه‌ای هنوز اضافه نشده است.
- `watch_after_deploy` خودکار restart نمی‌کند. پایش کوتاه‌مدت است؛ جایگزین مانیتورینگ ۲۴ساعته نیست.
- تشخیص قواعدی است؛ «مشاهده‌شده» به معنای مشاهدهٔ سیگنال است، نه اثبات علت ریشه‌ای. عدد confidence احتمال آماری کالیبره‌شده نیست.
- parser متریک و فرض واحدها تا دریافت نمونهٔ واقعی حساب قطعی نیست؛ بر پایهٔ این اعداد نباید خودکار پلن ارتقا داد.
- baseline به‌ازای اپ است؛ تشخیص جدید baseline قبلی را جایگزین می‌کند. verify_fix شناسهٔ ناهماهنگ را رد می‌کند.
- approval/state برای یک فرایند محلی است؛ multi-process locking، رمزگذاری state و sandbox تولیدی ندارد. دسترسی پوشهٔ `.agate` باید محدود باشد؛ مقادیر envِ pending به‌صورت محلی ذخیره می‌شوند و فقط خروجی‌ها ماسک هستند.
- لاگ‌ها دادهٔ غیرقابل‌اعتمادند؛ LLM اجازهٔ تولید عملیات ندارد و فقط علت‌های قواعدی را رتبه‌بندی می‌کند. ماسک‌کردن اسرار شناخته‌شده جایگزین حذف همهٔ اطلاعات حساس دلخواه در لاگ نیست.
- دمو دارای fault injection عمدی است؛ برای محیط تولید مناسب نیست. پنل با کلید خالی بسته است؛ کلید فقط روی اپ آزمایشی تنظیم شود.
- ضبط ویدئو، ارسال مسابقه، public کردن مخزن، push و عملیات هزینه‌دار انجام نشده‌اند.

## وضعیت milestone
M0: build / MCP محلی بررسی‌شده. M1: توکن تنظیم شد و preflight اجرا شد، اما DNS میزبان‌های API شکست خورد؛ احراز هویت هنوز سنجیده نشده است. M2: تست سایت محلی موجود؛ خواندن live مسدود. M3–M5: مسیرهای محلی و بخشی از ایمنی تست شده؛ پذیرش live انجام نشده و موارد بالا باقی‌اند. M6: اسناد و smoke محلی موجود؛ آمادگی مسابقه ادعا نمی‌شود.
